# Подключение формы заявки

В режиме предпросмотра поля отключены и посетитель видит соответствующее сообщение. В коммерческой сборке форма включается, когда в `src/company.ts` указан ID Formspree. Проверьте условия сервиса, предполагаемый объём заявок и обработку данных до запуска. Formspree позиционирует бесплатный тариф для тестирования и разработки. [Тарифы Formspree](https://formspree.io/plans)

1. Создайте аккаунт Formspree, подтвердите рабочую почту и добавьте форму через **New Form**. Настройте получателя в **Workflow**. [Создание формы](https://help.formspree.io/articles/building-your-form/building-an-html-form/) · [Адрес получателя](https://help.formspree.io/articles/form-and-project-settings/changing-a-form-email-address/)
2. Из адреса вида `https://formspree.io/f/FORM_ID` скопируйте только `FORM_ID` в поле `formspreeId`. ID публичный. API-ключ для этой интеграции не нужен.
3. Утвердите текст политики на ET, RU и EN. Уточните сведения об операторе и способе связи, цели и основания обработки, получателей, условия хранения, передачу данных и права посетителя. Проверьте договор и настройки обработки у провайдера формы. [GDPR, статья 13](https://eur-lex.europa.eu/eli/reg/2016/679/oj) · [Безопасность Formspree](https://formspree.io/security/)
4. На коммерческом домене отправьте тестовый запрос, убедитесь, что он появился в Formspree и дошёл до рабочего почтового ящика. Проверьте обязательные поля, локализованное сообщение об успехе и повторную попытку после ошибки. Если включаете **Restrict to Domain**, проверьте доставку именно с конечного домена. [Настройка домена Formspree](https://help.formspree.io/articles/form-and-project-settings/restrict-to-domain)

Форма передаёт имя, телефон, email, тип работ, сообщение, язык и отметку об ознакомлении с политикой. С JavaScript сообщение об успехе появляется после ответа сервиса. Без JavaScript отправка выполняется обычным POST, результат показывает Formspree.
